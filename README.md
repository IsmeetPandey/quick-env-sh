## ⚡ Highlights

- **POSIX Standard Compliant**: Zero external bashisms — runs flawlessly on `sh`, `dash`, `bash`, and `zsh`.
- **Idempotent by Design**: Safe to re-run across existing workspaces without overwriting custom local overrides.
- **Cross-Platform OS Detection**: Out-of-the-box support for Ubuntu, Debian, Arch, Alpine, macOS, and WSL.

---

## 🚀 One-Line Execution

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/IsmeetPandey/quick-env-sh/main/bootstrap.sh)"
```
